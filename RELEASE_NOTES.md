Fast DDS with three shared-memory transport fixes (see the README): one package per ROS 2 release and architecture, each a drop-in replacement for the ROS apt package of the same version with `+husarion4` appended. Verify downloads against `SHA256SUMS`.

v2 keeps the v1 fix and adds two. After a process on the host dies uncleanly, the other processes no longer split the discovery port among themselves (newcomers kept missing part of the world until everything restarted). A sender also no longer spins forever on the dead process's port, which used to leave it publishing nothing and deaf to new participants. Install it in every image whose processes share the robot's `/dev/shm`, as with v1. Patched and unpatched processes can share a world, but only the patched ones are protected.
