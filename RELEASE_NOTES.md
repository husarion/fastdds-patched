Fast DDS with four shared-memory transport fixes and an opt-in host id override (see the README): one package per ROS 2 release and architecture, each a drop-in replacement for the ROS apt package of the same version with `+husarion8` appended. Verify downloads against `SHA256SUMS`.

v6 follows the ROS repository's Humble sync of 2026-10-31, which rebuilt Fast DDS 2.6.12 as `2.6.12-1jammy.20261031.123121`. The source package and its version did not change, but the new build stamp sorts above v5's Humble package (built on the earlier `2.6.12-1jammy.20260723.233918`), so apt refused v5 as a downgrade in any image that upgrades its ROS packages. v6 rebuilds Humble on the new binary with the same three fixes, unchanged. Jazzy (2.14.7) and Lyrical (3.6.2) did not move in the repository and are rebuilt from the same sources and patches as v5, with the new version suffix. Processes on v6 and v2 to v5 share the same shared-memory code and lock protocol and can share a world.
