Fast DDS with three shared-memory transport fixes (see the README): one package per ROS 2 release and architecture, each a drop-in replacement for the ROS apt package of the same version with `+husarion5` appended. Verify downloads against `SHA256SUMS`.

v3 carries the same three fixes as v2 and follows the ROS repository to Fast DDS 2.14.7 on Jazzy. The repository has shipped 2.14.7 since its sync of 2026-09-11, and an image that installs it can no longer take the v2 package, which is built on 2.14.6 (apt refuses the downgrade). Fast DDS 2.14.7 does not change the shared-memory transport and still has all three bugs, so the patches carry over unchanged. Humble (2.6.12) and Lyrical (3.6.2) are rebuilt from the same sources and patches as in v2. Install it in every image whose processes share the robot's `/dev/shm`, as before. A v3 Jazzy process and a v2 one can share a world: the shared-memory layout and the lock protocol of the fixes are the same in both.
